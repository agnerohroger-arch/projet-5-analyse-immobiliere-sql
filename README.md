# Projet 5 — Analyse des transactions immobilières avec SQL

## Présentation du projet

Projet réalisé dans le cadre de ma formation Data Analyst chez OpenClassrooms.

L'objectif était de créer et d'exploiter une base de données relationnelle pour analyser le marché immobilier français à partir des données DVF et INSEE, sur le premier semestre 2020.

## Problématique métier

Comment exploiter les données immobilières pour identifier les tendances du marché, comparer les territoires et fournir des indicateurs utiles à la prise de décision ?

## Méthodologie

1. Étude des sources de données DVF et INSEE.
2. Conception d'un modèle de données relationnel.
3. Préparation, nettoyage et intégration des données.
4. Création et interrogation de la base de données avec SQL.
5. Réalisation de 12 analyses SQL et interprétation des résultats.

## Compétences mobilisées

- SQL : SELECT, WHERE, JOIN, GROUP BY, COUNT, AVG et fonctions de classement.
- Modélisation de bases de données relationnelles.
- Nettoyage et contrôle de qualité des données.
- Analyse géographique et temporelle des transactions.
- Restitution des résultats à travers une présentation métier.

## Résultats présentés lors de la soutenance

- 31 378 ventes d'appartements recensées dans le périmètre étudié.
- 12 121 €/m² : prix au mètre carré observé à Paris dans l'analyse.
- +3,68 % : évolution trimestrielle calculée dans le projet.

Ces indicateurs correspondent aux résultats de l'étude réalisée dans le cadre de la formation et ne constituent pas des statistiques actualisées du marché immobilier.

SQL · Base de données relationnelle · Excel · PowerPoint
